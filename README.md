# Проект

Приложение для анализа банковских транзакций из Excel-файла.
Генерирует JSON для веб-страниц, строит отчеты, ищет транзакции, рассчитывает кэшбек.

## Возможности
1. Главная страница: приветствие по времени суток, расходы по каратм, топ-5 транзакций, курсы валют
2. Сервис "Выгодные категории повышенного кешбека" - расчет потенциального кешбека по категориям за месяц.
3. Сервис "Простой поиск" - поиск транзакций по описанию и категории.
4. Отчет "Траты по категории" - все траты за последние 3 месяца с сохранением JSON-файла.
5. Логирование действий.
6. Тестирование с pytest (покрытие больше 80%).

## Технологии

1. Python 3.13
2. Pandas, openpyxl - работа с эксель
3. Requets - вызов АПИ
4. Poetry - управление зависимостями
5. Flace8, Black, isort, mupy - линтеры
6. Pytest, pytest-mock - тесты
